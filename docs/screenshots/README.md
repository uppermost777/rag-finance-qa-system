# 界面截图

取自实际运行的演示环境（阿里云 ECS 2 核 4GB，`docker-compose.lite.yml`：redis + app + nginx
三容器，SQLite + Milvus Lite）。分辨率 1440×1050，DPR 2。

| 文件 | 页面 | 说明 |
|---|---|---|
| `01-login.png` | 登录页 | JWT 登录，演示账号一键填充（`admin` / `student_lin`） |
| `02-chat.png` | 智能问答 | 一次完整问答：结论 + 分点解释 + `[1][2]` 引用 + 可展开来源（文件名/页码/片段/相似度），顶部显示策略与平均延迟 |
| `03-risk.png` | 风险测评 | 10 题提交后的五维雷达图、C4 成长型等级、推荐学习路径 |
| `04-kb-admin.png` | 知识库管理 | 6 个知识库 / 50 篇文档分页，入库状态 `done`、切片数与重建索引按钮 |

截图要点（用于复现）：

- `02-chat.png` 用的是「纯向量检索」，相似度是余弦分值（0.7+），直观可读；若切到
  「混合检索（RRF）」，来源里显示的是 RRF 融合分，只有 0.0x 量级，属正常现象。
- 首次请求会加载 bge-m3 / 重排模型（约 20s），截图前先 warm-up 一次，避免平均延迟被冷启动拉高。
- 页面主内容区是独立滚动容器，`full_page=True` 无效，需按视口截图。
