# 截图清单（待补）

当前开发机的沙箱禁止 esbuild 遍历上级目录，`npm run build` 无法执行，因此未能自动截取前端页面。
请在普通开发机上按以下步骤补齐截图，放到本目录：

```bash
# 1) 启动后端（本地或 Docker）
uvicorn app.main:app --reload --port 8000
# 2) 启动前端
cd web && npm install && npm run dev
# 3) 浏览器打开 http://127.0.0.1:5173，登录后截图
```

| 文件名 | 页面 | 建议内容 |
|---|---|---|
| `chat.png` | 对话主界面 | 一次带引用来源的完整问答 + 右侧会话列表 |
| `chat-stream.png` | 对话主界面 | 流式生成中（显示"生成中…"与已出现的引用） |
| `kb-admin.png` | 知识库管理 | 上传后的文档列表、入库进度条 |
| `risk.png` | 风险测评 | 五维雷达图 + 风险等级 + 学习路径 |
| `profile.png` | 个人中心 | 提问统计卡片与会话列表 |
| `swagger.png` | 接口文档 | http://127.0.0.1:8000/docs |

建议使用 1440×900 分辨率，浏览器缩放 100%，截图后直接替换 README 第二节的占位路径。
